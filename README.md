# BotCV Dashboard

Prototipo web dashboard per gestione profili, proxy, prodotti e commenti.

## Avvio locale

```bash
pip install -r requirements.txt
streamlit run dashboard.py
```

Credenziali test:
- admin / admin123
- demo / demo123

## Deploy su Streamlit Cloud

1. Questo repo è pronto.
2. Vai su https://share.streamlit.io
3. Collega il repo e seleziona `dashboard.py` come main file.
4. Ottieni un link pubblico.
